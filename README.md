# Telco Customer Churn Analysis

## Project Overview
This project analyses customer data to investigate factors associated with customer churn.

## Dataset
- File: `Telco_customer.csv`
- Format: CSV

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Business Questions
1. Which type of contract has the highest customer churn?
2. Does customer tenure affect the likelihood of churn?
3. Do customers with higher monthly charges churn more often?
4. Which internet service type has the highest customer churn?
5. Are customers using electronic payment methods more likely to churn?

## Initial Data Inspection
The dataset is loaded using pandas. Initial checks include the dataset dimensions, column information, descriptive statistics, missing values, and duplicate rows.
